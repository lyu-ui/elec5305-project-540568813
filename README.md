# elec5305-project-540568813

## Project Title
Analysis of Audio Signal Representations for Liquid Fill-Level Estimation from Pouring Sounds

## Overview
This project investigates how different audio signal-processing representations and features can be used to estimate liquid fill level from pouring sounds.

The project will use MATLAB and publicly available pouring-audio recordings. An STFT-based system will be developed as a baseline, followed by the evaluation of suitable signal-processing methods introduced during ELEC5305.

## Main Techniques
- FFT and spectral analysis
- Short-Time Fourier Transform (STFT)
- Spectrogram analysis
- Spectral features
- Audio feature extraction
- Feature-based fill-level classification
