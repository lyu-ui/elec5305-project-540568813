What the error means. Results compare estimated air-column length with an assumption-derived filling reference. This study has no independently measured liquid-level trajectories, so the reported errors do not establish real liquid-level accuracy.

From acoustic evidence to reliability

A smooth-looking resonance does not guarantee a correct physical estimate. This study asks whether interpretable spectral features can identify less reliable portions of a recording, and where that approach fails.

Analysis

A frozen predictor, an interpretable score

The pretrained Sound of Water network supplies pitch-related predictions. Five acoustic features describe peak prominence, competing peaks, frame-to-frame continuity, spectral entropy and support near the model frequency. A regularized score is fitted only on development recordings.

Evaluation

Keep the container groups separate

The selected set contains 11 development clips, 8 seen-container test clips, 8 unseen-container test clips and 6 shape diagnostics. Test targets are not used to fit the score. Results average recordings equally; uncertainty is assessed by resampling containers.

Selection helps on seen containers

At 70% frame retention, the combined score reduces reference error on the seen subset. Evidence for an improvement on unseen containers is inconclusive.

One endpoint can shift the whole trajectory

The physical conversion subtracts the model's final wavelength estimate. A pitch switch at that endpoint can introduce a global offset, even when much of the earlier acoustic ridge looks plausible.

Geometry changes the reference

For tapered containers, a constant-volume filling model changes the assumed reference curve. Lower disagreement under that alternative is sensitivity to a reference assumption; the underlying prediction has not improved.

Controlled tests clarify the limits

A two-resonator LPC control tests known frequency recovery. Wiener experiments quantify noise reduction and peak distortion. Coarse frequency pooling illustrates loss of competing-peak detail, without claiming a validated perceptual model.

Compare noise removal and listening quality

The controlled comparison uses a six-second pouring excerpt, a fixed 10 dB noise condition and two Wiener filtering variants. Four shared-gain audio files are generated locally during setup.

Four versions of the same excerpt

  1. Original pouring segment
  2. Added Gaussian noise
  3. Estimated Wiener filtering
  4. Oracle Wiener filtering

After preparing the project, run R = run_project(true); in MATLAB to hear the originals and processed comparison sequentially. Use a comfortable listening volume.

What the listener reported

One informal, unblinded listener reported clear noise in version 2, clear water sound in version 3, intermittent sound in version 4 and no obvious difference between versions 1 and 3.

The oracle uses clean-signal information and is a diagnostic benchmark. These observations are not a controlled listening study or evidence of zero distortion.

Run the complete analysis

Source metadata, cached model predictions and reproducible analysis code are included. One setup command fetches the original public recordings, checks their hashes and recreates all experiment inputs. No neural-network checkpoint is needed for the normal analysis.

Verification

Recorded execution, explicit checks

The numerical helpers were executed in base MATLAB R2025b Update 6. The recorded four-table audit shows agreement with the independent Python reference within explicit tolerances. Summary tables and selected figures are retained; full frame tables are regenerated locally.

The standalone entry point calls those unchanged helpers and passed static checks; this new wrapper has not itself been executed in MATLAB in the packaging environment. Python also provides bootstrap, development-fold and endpoint analyses.
